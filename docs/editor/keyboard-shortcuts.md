# Keyboard shortcuts

<!-- Generated from the editor's command catalog (CommandCatalog::markdownReference, also
     Help > Keyboard Shortcuts). Do not edit by hand: the unit test
     CommandCatalog.MarkdownReferenceMatchesDocs fails when this file is out of date. -->

The editor's default key bindings, by group. Rebind any of them in **Edit > Shortcuts...**; your
changes are kept in `shortcuts.yaml` in the editor's settings folder and apply to every project.
**Edit > Search All...** (Ctrl+K) finds any command by name, with its shortcut.

- On macOS, Ctrl is the Command key (Cmd) and Alt is Option.
- **Context** says where a key works: *Global* everywhere, the Code Editor and text fields included;
  *Editor* in every window but the Code Editor, and not while typing in a field; a window's name
  while that window has focus (the Scene View also while the mouse is over it).
- Letters follow the keyboard layout: on AZERTY the Hand Tool is the key labelled Q.
