Scope and accounting

The audit covered every first-party test definition in editor/tests,
editor/htmlui/tests, editor/texsynth/tests and engine/tests, plus all cases
collected by the default tools/mcp/run_tests.py runner. The original inventory
contains 2,890 named definitions/generated Python case names: 1,955 C++ and 935
Python. Parameterized C++ definitions expand to more runtime cases; these are
not interchangeable counting units. Vendor/upstream library test suites and
separate research benchmarks were not audited as first-party product tests.

Standalone prefab scripts contribute 180 original assertion sites. Together
with nine harness, migrated smoke and critical export workflow groups, their
189 additional dispositions are recorded separately. They are not added to
the framework-definition totals.

The current audit snapshot assigns 424 DELETE, 213 REWRITE, 106 OPTIMIZE,
144 CONSOLIDATE and 2,003 KEEP decisions to the 2,890 original names. These are
dispositions, not mutually interchangeable counts of removed executions:
CONSOLIDATE includes both eliminated executions and surviving owners, and
rewrites can rename cases. Current collection contains 2,363 names: 2,345
original names plus 18 renamed/consolidated names, a net reduction of 527.
These figures are the final primary audit/collection snapshot. The original
inventory remains fixed; all incoming default-runner sources were checked.

Changed test source files in the five owned test directories
(*.cpp, *.h, *.py) add 2,109 and remove 18,143 lines: net -16,034 test-source
LOC across 205 files. This excludes documentation/audit records, fixture
bytes, snapshots and production-source cleanup; those categories are not
combined to inflate the test-source reduction.

Every individual disposition is in dispositions.jsonl, one JSON object per
original named test, keyed by path and name. ancillary-dispositions.jsonl
covers the 189 standalone checks/groups. For retained or changed coverage,
contract/source, bug, oracle, seam, refactor and unique fields explain the
six behavioral-bar requirements; reason describes the disposition and
validation gives its command. DELETE reasons identify the failed bar and
remaining owner where one exists. original_name_survives distinguishes an
eliminated original name from a surviving consolidation owner. These files
are the named-definition test-by-test report, not a sample or a
coverage-percentage proxy. runtime-parameters.jsonl additionally records all
2,196 original instantiated GTest parameter/typed variants, each explicitly
linked to its primary owner and retaining its six behavioral-bar fields,
fixture/type identity and baseline timing. There are no missing or ambiguous
owner mappings. Runtime rows are not added to the primary definition count.
Unscoped historical seconds/timing fields were removed rather than
reclassified as measurements. Five provenance-bearing measured_performance
series remain. execution_observations attaches actual source-qualified
GTest/MCP outcomes and elapsed values where available; parameter details
have their own runtime ledger. Their audit-time validation notes must be
read alongside the actual
gate results in validation.txt; an audit command is not a claim it passed.

The runtime ledger explicitly overrides 73 unsupported Taffy cases as

(162 RCSS, 115 diagnostics, 26 RML) and 28 PNG goldens. Removed 113 orphan input

pixels, independently checked; all clip pixels and tolerances are unchanged.
A font reload fixture explicitly authors contrasting white text so its
nonempty-glyph assertion cannot silently observe only the background.
