# S32 manual check (AC16)

Run in an isolated editor on a scratch project (GL), with a 3D scene holding a few lit spheres.
Each step names what to see. Screenshots go with the record of the run, not into the repository.

## Status bar and stand-ins

1. Select a sphere. In the Inspector's Advanced Surface group, turn on Clear Coat. The status bar
   shows "Compiling shaders N" on its left until the variant is created; its tooltip gives the
   mode (worker on desktop GL) and the render thread's milliseconds. It then disappears.
2. Meanwhile the sphere keeps drawing (its plain variant) and the material's variant line reads
   "Compiling...". It then draws the coat, and the line reads "Ready".
3. Ctrl+Z: the coat goes, at once (the plain variant is ready).

## Project Settings > Graphics

4. The sections Shader Creation (Asynchronous Shader Creation, Main Thread Budget (ms), GL Warm
   Draws) and Shader Warm-up (Record During Play, Include in Builds, Hold First Scene, Warm-up
   List) are there. Each row has its tooltip.
5. Type "warm-up" in the settings search: only the Shader Warm-up rows (and the page) stay.
6. Set Main Thread Budget to 6, Apply, then Ctrl+Z: it reads 2 again (Edit > Undo names
   "Change Shader Creation Settings").
7. Turn Asynchronous Shader Creation off and Apply: the Console logs `[gpu] shader creation: sync`.
   A new lobe now stalls the frame, as before S32. Turn it on again: `[gpu] shader creation: worker`.

## Warm-up list

8. Turn on Record During Play, Apply, press Play, wait, Stop. The Console logs "Shader warm-up
   list: N shaders, M pipelines (ShaderWarmup.json)". The Warm-up List row counts them.
9. Click Clear: the row reads "0 shaders, 0 pipelines"; the search palette's command "Clear Shader
   Warm-up List" does the same.
