# S15 manual check (AC14, AC6)

Run in the editor with a 3D scene that has a few meshes, a shadowed directional light and the
post-processing Bloom on. Each step names what to see.

## Profiler (AC14)

1. Click the FPS in the status bar: Window > Analysis > Profiler opens (Ctrl+7 too).
2. Press **Record**, enter Play mode, wait a few seconds. The CPU Usage chart fills with stacked
   categories; GPU Usage stacks pass families (or reads "GPU timing unavailable: <reason>").
3. Click a frame in the CPU Usage chart: the slider and the "Frame N" label move to it, the
   other charts mark the same frame, the Hierarchy shows that frame.
4. Hierarchy: sort by Self ms and by Calls (the header), search "Draw", pick a Job Worker thread.
5. Timeline: one lane per thread with the job workers ("Job Worker #n"); the wheel zooms, a drag
   pans, the tooltip shows name, duration and depth; a click selects the scope, the Hierarchy
   highlights its row.
6. Set the budget to 60 fps: a line at 16.7 ms on CPU Usage and GPU Usage.
7. GPU Usage detail: the pass table with GPU ms, CPU ms, draws and the semantics note.
8. GPU Memory: the category bars, the allocation table by category and by owner, the filter;
   "Driver: n/a" on llvmpipe, a used/budget line on lavapipe or a desktop GPU.
9. Monitors: check "Triangles": the Monitors chart draws it.
10. Save, then Clear, then Load the file: Target reads "Capture N", the frames come back.
11. Pause on frame > 30 ms, then make a long frame (a script that busy-waits): recording stops on
    that frame and selects it.

## Frame Debugger (AC14)

1. Window > Analysis > Frame Debugger, Enable. The view selector lists Scene / Game.
2. The pass tree lists the frame's passes in order, the shadow passes folded ("... x4").
3. Select the bloom pass: targets with load/store actions, draws, CPU and GPU ms.
4. Preview: Color, Alpha, R, G, B change the image; pick the Depth attachment of the scene pass,
   Depth mode, then Levels and Linear (near/far).
5. Freeze: the list stops changing while the scene animates.

## Platforms (AC6), with screenshots in the pull request

- Windows D3D11, macOS Apple silicon Metal (the note reads "encoder spans overlap"), Android
  GLES3 (a Development Build, `--profile-capture` or the Profiler on an editor running the game),
  Chrome WebGL2: Profiler > GPU Usage shows per-pass ms.
- Firefox WebGL2: "GPU timing unavailable: extension_missing".
