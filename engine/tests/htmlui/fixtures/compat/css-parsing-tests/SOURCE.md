# css-parsing-tests

Copied unchanged from https://github.com/SimonSapin/css-parsing-tests at commit
`203ce36bffd617db7f118c551e32794561fb273d` (2025-09-24). License: CC0 1.0 (`LICENSE`).

Used by `engine/tests/htmlui/compat/compat_tokenizer_test.cpp` and `compat_parser_test.cpp`
(phase-2 p2-core) and by the colour tests of p2-css (`color_*.json`). The expectations follow
the 2021 CSS Syntax draft; where the 2024 draft the compat parser implements (CSS Nesting)
differs, the tests list each case and why.
